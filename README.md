# User Stories
1. As a user, I want to be able to search up courses and see their description/requirements
2. As a user, I want to be able to see past course evaluations for a given course
3. As a user, I want to be able to create course plans for any number of semesters
4. As a user, I want to be able to create multiple different course plans
5. As a user, I want to be able to import and export my course plans
6. As a user, I want to be able to see whether or not I am eligible to take a given course in a given semester
7. As a user, I want to be able to record my achieved grade for a given course and see my CGPA automatically calculated
